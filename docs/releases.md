## 中文

### 问题修复

- 修复 DSH rc.3 顶栏结构变化引起的标题挤压、按钮越界及视图标签间距异常。
- 协调 Codex 与 Cursor 风格顶栏的内容宽度、空占位和 macOS 原生窗口预留，改善主题切换与窄窗口表现。

<a id="en-0175"></a>

## English

### Bug Fixes

- Fix squeezed titles, overflowing actions and incorrect view-tab spacing caused by the DSH rc.3 header structure.
- Align content sizing, empty leading slots and native macOS window clearance in Codex and Cursor headers, improving theme switching and narrow windows.

## 安装 / Installation

在 **插件 → 添加插件** 使用下方固定包。精确宿主为 **DSH 0.2.1-rc.3**；保留原 profile、配置和正式会话，待任务结束后完整重启。

Install the fixed package through **Plugins → Add plugin** on **DSH 0.2.1-rc.3**. Preserve the profile, settings and existing conversations, then restart after active tasks finish.
